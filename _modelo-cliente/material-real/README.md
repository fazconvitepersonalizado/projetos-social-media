# Material real do cliente

O que tira a cara de IA de um carrossel não é regra: é coisa que só este cliente tem.
Aqui fica o que o cliente conta e manda, para virar gancho, caso, fala e foto.

## Coleta mensal (10 minutos, por WhatsApp ou áudio)
Todo mês, antes de planejar o mês seguinte, o Thiago manda as 3 perguntas:

1. O que aconteceu num atendimento, visita ou trabalho seu este mês que te marcou?
2. Que dúvida um cliente te fez (do jeito que ele perguntou)?
3. Tem foto disso? (do lugar, do material, de você trabalhando; sem rosto de cliente sem autorização)

A resposta vai para `<AAAA-MM>.md` nesta pasta, do jeito que veio (áudio transcrito,
sem enfeitar), e as fotos para `fotos/<AAAA-MM>/`.

## Como usar
- **Caso real** vira slide de gancho ou de "por que importa", sempre anonimizado (sem
  nome de empresa ou pessoa, salvo autorização escrita).
- **Dúvida real** vira tema de carrossel, título de pergunta ou legenda.
- **Fala real** só entra entre aspas se foi dita de verdade e o cliente autorizar.
- **Foto própria** vem antes de foto de banco; passa pelo mesmo tratamento (recorte,
  ajuste leve, véu da marca).
- Nunca completar o que faltou com invenção. Sem material no mês, o sorteio evita as
  composições que pedem material real (caso, fala, dado do cliente).
- Ao usar, anotar no arquivo do mês: "usado em POST NN de AAAA-MM".
